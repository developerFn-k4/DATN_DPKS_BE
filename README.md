# DATN_DPKS_BE

## Giới thiệu
Đây là project backend quản lý khách sạn được xây dựng bằng Laravel.

## Thành viên thực hiện
- Hung Dang

## Công nghệ sử dụng
- Laravel
- MySQL
- RESTful API

## Hướng dẫn chạy project
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
